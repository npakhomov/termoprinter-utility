# ThermoPrinterTool

Windows-утилита для пошаговой настройки и диагностики термопринтеров. Приложение собирает в одном месте проверку USB и сети, поиск сетевых параметров, загрузку фирменных утилит и драйверов, тихую установку драйверов и создание TCP/IP-порта Windows.

Версия: **0.1.10-beta**. Меры безопасности режима поддержки и ограничения проверки описаны в [SUPPORT-SECURITY.md](SUPPORT-SECURITY.md).

В этой версии: SHA-256 для архивов DD340/BP41, обычный запуск без прав администратора с отдельным UAC для установки, удаление клиентской копии EXE после закрытия и защита от конфликтов DHCP. Автопроверка обновлений сохранена: перезапуск ожидает завершения текущей операции, а закрытие окна отменяет загрузку. Подготовка утилиты использует сохранённые проверенные параметры, а тайм-аут установщика не удаляет используемые им файлы.

## Поддерживаемые модели

| Модель | Утилита | Драйвер и TCP/IP-порт |
| --- | --- | --- |
| ATOL DD340 | Автоматическое скачивание и запуск HPRT Printer Utility | Тихая установка `HPRT HD200 - ZPL`, создание порта и принтера Windows |
| ATOL BP41 | Автоматическое скачивание и запуск RTLabelPrinterTool | Тихая установка `Rongta RP4xx Series`, создание порта и принтера Windows |
| TSC DA220 | Открытие официальной страницы утилиты | Используется установленный драйвер подходящей модели |
| BIXOLON XD3-40d | Открытие официальной страницы утилиты | Используется установленный драйвер подходящей модели |

Автоматизация для TSC DA220 и BIXOLON XD3-40d будет расширяться по мере проверки фирменных пакетов на реальном оборудовании.

## Сценарии работы

При запуске доступны два режима:

### Настройка принтера с нуля

1. Выбрать модель и назначение принтера в Windows.
2. Нажать **Проверить USB подключение**. Программа ищет физическое USB-устройство, похожее на выбранную модель, даже если драйвер еще не установлен.
3. Если известен DHCP-пул роутера, заполнить поля **DHCP от** и **DHCP до**. Нажать **Найти свободный IP**. Программа исключит этот пул и покажет только адрес-кандидат, маску и шлюз. Перед постоянным назначением согласовать резервирование DHCP или исключение статического адреса с техником.
4. Нажать **Скачать или запустить утилиту**. Для DD340 и BP41 архив проверяется по SHA-256 из кода и распаковывается в отдельную папку `%USERPROFILE%\Documents\Label_printer\Verified`. Архивы кэшируются в `%LOCALAPPDATA%\ThermoPrinterTool\Packages` и проверяются при каждом использовании. Старые непроверенные распакованные копии не используются.
5. После назначения сетевых параметров принтеру нажать **Проверить ping**.
6. Нажать **Скачать и установить драйвер**. Windows запросит UAC только для отдельного процесса установки DD340/BP41. Процесс проверит закрепленный SHA-256 архива в защищенном каталоге, выполнит установку без мастера и завершится. UAC нельзя отключить или обойти.
7. Нажать **Создать TCP/IP порт**. Программа проверит доступность принтера, создаст стандартный порт Windows и добавит или обновит принтер с выбранным назначением.

### Диагностика проблем с подключенным принтером

Программа получает сетевые принтеры Windows и автоматически проверяет их доступность. В окне диагностики можно:

- повторить проверку;
- сравнить сеть компьютера и сеть принтера;
- перезапустить Dodo Label Printer;
- запустить повторную настройку IP для ATOL DD340 или ATOL BP41;
- открыть настройки выбранного принтера Windows.

## Как определяется свободный IP

Свободный IP сейчас определяется **не только по отсутствию ping**.

Программа:

1. Выбирает активный IPv4-адаптер, отдавая приоритет обычной сети с основным шлюзом перед VPN и виртуальными адаптерами.
2. Вычисляет реальный диапазон адресов по IP и маске подсети.
3. Исключает локальные адреса компьютера, шлюз, известные TCP/IP-порты принтеров и указанный пользователем DHCP-пул.
4. Перебирает адреса текущей подсети без предположения, что диапазон `200-254` безопасен. За один поиск проверяется до 512 кандидатов.
5. Через Windows API `SendARP` запрашивает MAC-адрес на выбранном сетевом интерфейсе и проверяет ping. Ошибки интерфейса не считаются признаком свободного адреса.
6. Показывает первый адрес без ответа как **IP-кандидат**, а не как гарантированно свободный IP.

Отсутствие ответа не гарантирует свободный адрес: устройство может быть выключено, а DHCP-сервер может выдать адрес позже. Универсально прочитать пул произвольного роутера нельзя. Рекомендуется включить DHCP на принтере и закрепить адрес за его MAC на роутере. Если используется статический IP, техник должен исключить его из DHCP-пула. Программа не меняет конфигурацию роутера.

- удаление пользовательского EXE после штатного выхода из программы.

## Установка и запуск

Скачайте `ThermoPrinterTool.exe` со страницы [Releases](https://github.com/npakhomov/termoprinter-utility/releases) и запустите его. Приложение публикуется одним self-contained EXE и не требует отдельной установки .NET.

Окна диагностики, сетевые проверки и загрузки работают без запроса UAC. Установка драйвера требует отдельного подтверждения Windows. Создание порта и очереди сначала выполняется с текущими правами и запрашивает UAC при отказе в доступе.

После закрытия всей программы пользовательский single-file EXE удаляется. Драйверы, принтеры Windows и файлы производителя сохраняются. Рабочие копии внутри дерева Git или исходного проекта и отладочные сборки защищены от автоудаления. Принудительное завершение процесса или запрет на удаление файла могут потребовать ручного удаления EXE.

## Разработка

Требования:

- Windows;
- Visual Studio с поддержкой .NET Desktop Development;
- .NET 10 SDK.

Откройте `ThermoPrinterTool.slnx` и нажмите `F5`.

Сборка одного EXE:

```powershell
dotnet publish ThermoPrinterTool.csproj -c Release -r win-x86 --self-contained true -p:PublishSingleFile=true
```

Результат появится в `bin\Release\net10.0-windows\win-x86\publish`.

Проверки безопасности без установки драйверов и изменения принтеров:

```powershell
dotnet run --project Tests\SecurityChecks.csproj -c Release
```

Дополнительный аргумент с путем к четырем архивам `dd340-driver.zip`, `bp41-driver.zip`, `dd340-utility.zip`, `bp41-utility.zip` включает проверку реальных архивов:

```powershell
dotnet run --project Tests\SecurityChecks.csproj -c Release -- "C:\path\to\archives"
```
